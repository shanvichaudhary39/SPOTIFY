About This Demo Player

A lightweight local music player UI built for learning and quick demos.

Our Goal

Provide a clean, responsive interface to play local audio files and demonstrate basic player controls (play, pause, next, progress).

Features

  • Play local .mp3 files
  • Master and per-track controls
  • Responsive layout for mobile and tablet

How to Use

Open the main page, click a track to play, and use the bottom controls to navigate or change progress.

Contact

If you want more features (search, playlists, upload), open an issue or request changes in the project folder.
