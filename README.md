# Spotify Music Player

A Spotify-inspired music streaming web app built with HTML, CSS, and JavaScript. This project recreates a clean music-player interface with playlist navigation, playback controls, and responsive styling.

## Overview

This project simulates a modern music listening experience with:

- A Spotify-inspired landing page
- Playlist-based song selection
- Play, pause, next, and previous controls
- Playback progress bar and time indicators
- Multiple pages such as Home, About, Playlist, and Login

## Features

- Play and pause songs from a music list
- Skip to the next or previous track
- Real-time progress tracking
- Active song highlighting
- Clean and modern user interface inspired by Spotify
- Lightweight frontend application with no backend required

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/shanvichaudhary39/SPOTIFY.git
```

2. Open the project folder:

```bash
cd SPOTIFY
```

3. Start a local server (recommended):

```bash
python -m http.server 8000
```

4. Open your browser and visit:

```bash
http://localhost:8000
```

5. Open `index.html` directly if you prefer a quick preview.

## Usage

- Click any song in the playlist to start playing it.
- Use the play/pause button to control playback.
- Use the forward and backward buttons to switch tracks.
- Drag the progress bar to jump to a specific point in the current track.

## Notes
